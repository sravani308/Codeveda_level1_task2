# Codveda_level1_task2

## Number Guessing Game

This project is a console-based Number Guessing Game developed as part of the Codveda Technology Java Development Internship.

## Features
- Random Number Generation
- User Guess Validation
- Too High / Too Low Hints
- Limited Attempts
- Replay Option

## Technologies Used
- Java
- Random Class
- Scanner Class
- Loops
- Conditional Statements
